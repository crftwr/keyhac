# Why three references are missing here

Three of this skill's references are **copied in at bundle time** rather than
checked in here, and `tools/build_skill_bundle.py` is where that is wired:

| In the bundle | Copied from |
|---|---|
| `references/configuration.md` | `doc/configuration.md` |
| `references/config-api.md` | `doc/config-api.md` (generated by `make api-reference`) |
| `references/action-api.md` | `doc/action-api.md` (generated by `make api-reference`) |

None of them is restated in a hand-written reference, and that is the point.
`doc/configuration.md` is already the authoritative description of key
expressions, table conditions, remapping and one-shot modifiers - maintained,
read by users, and corrected when it is wrong - and the two API references are
generated from the docstrings. A paraphrase of any of them living in the skill
would be a second copy to drift, and a confidently wrong rule costs more than a
missing one: that is exactly how `references/quirks.md` came to ship a false
statement about identifiers (issue #58).

So the hand-written references carry only what none of those do:
`key-tables.md` the loop and the rules for editing somebody's live `config.py`,
`actions.md` the rules for writing and running an action, `practice.md` what
each call costs, `quirks.md` where the platforms lie.

This file is excluded from the bundle: it is addressed to whoever is working on
Keyhac, not to the model.
